# API

- Implementar a API com Node.js e Express.
- Utilizar SQLite como persistência.
- Seguir exatamente as rotas, campos, respostas e códigos definidos em ../contrato-api.md.
- Regras de negócio devem vir de ../specs/.
- Antes de implementar uma regra, escrever um teste que demonstre a falha.
- Não modificar um teste correto apenas para fazer a implementação passar.
- Regras relacionadas a tempo devem utilizar o relógio controlável previsto no contrato.
