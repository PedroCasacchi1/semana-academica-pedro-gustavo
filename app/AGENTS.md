\# Interface



\- Desenvolver a interface com React e Vite.

\- A interface deve consumir exclusivamente a API definida em ../contrato-api.md.

\- Não inventar rotas ou campos diferentes do contrato.

\- Exibir ao usuário os erros relevantes retornados pela API.

\- A interface deve possuir testes automatizados.

\- Nos testes da interface, substituir a API real por uma API falsa ou mock.
